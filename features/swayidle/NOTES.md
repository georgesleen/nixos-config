# swayidle

## Workarounds

- `home.nix` / `battery-idle.sh`: Framework-only early idle actions dim the internal panel to at most 10% after 120 s and power it off after 300 s on battery. A mains-online supply overrides battery `Discharging` (charger supplementation is not battery mode). External outputs, AC behavior and the 1800 s lock/1801 s global off remain unchanged. Activity, resume, idle-service stop/start and a passive power-supply udev monitor restore owned dim/off state; a deliberate brightness change wins, and a disabled eDP-1 is never enabled. The `battery-idle` fixture suite covers these transitions and was proven red by reversing the mains override. These are ordinary swayidle timers and therefore obey compositor idle inhibitors.
- `home.nix` `screen-lock.service`: keyboard, idle, loginctl lock and before-sleep paths start the same foreground Hyprlock process. `Type=notify` waits for the compositor's `ext_session_lock_v1.locked` event; `pkgs/hyprlock/hyprlock-systemd-ready.patch` sends `READY=1` there because stock Hyprlock 0.9.6 has no readiness notification. A process start alone does not prove the screen is locked. `Restart=on-failure` restores an orphaned lock after a crash without relocking on a successful unlock. Isolated output removal/recreation, notification readiness, crash restart and clean exit were exercised; a physical KVM cycle remains a hardware check.
- `home.nix` Hyprlock layout has a glibc-date clock, a blank password box and a top status bar. `lock-screen-assets.py` queries awww at each lock, links the current wallpaper into the unit's runtime directory and generates the runtime config; Hyprlock blurs that image, never a screenshot of open windows. `lock-stats.nix` reuses Waybar's metric commands; `lock-bar.py` renders their Pango text into live PNG pills using the shared `status-style.nix` palette, absolute-pixel fonts and geometry. Only native network/profile/clock modules need adapters. GPU sampling state is isolated from the live bar; SSIDs are Pango-escaped. Workspaces, window titles, notifications and tray contents are not exposed. Screenshot capture and animations are disabled.
